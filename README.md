# Calculator

## Description

A simple calculator built using HTML, CSS, and JavaScript. The application performs basic arithmetic operations through a clean and responsive user interface. This project was created to strengthen my understanding of web development fundamentals and JavaScript programming.

---

## Technologies Used

- HTML
- CSS
- JavaScript

---

## Features

- Addition, subtraction, multiplication, and division
- Clear button to reset calculations
- Responsive design for desktop and mobile devices
- Real-time display updates
- User-friendly interface
- Keyboard input support

---

## Keyboard Shortcuts

| Key | Function |
|------|----------|
| 0–9 | Enter numbers |
| + | Addition |
| - | Subtraction |
| * | Multiplication |
| / | Division |
| Enter | Calculate result |
| Backspace | Delete last character |
| Esc | Clear display |

## The Process

1. Planned the calculator layout and required functions.
